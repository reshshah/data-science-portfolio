## VSC terminal commands to start a new virtual env where we will load all the python open source packages

## every new session run
source customer-intelligence-env/bin/activate


## One time setup:
python3 --version

## create an env
python3 -m venv customer-intelligence-env

## Activate it
source customer-intelligence-env/bin/activate

## Tell VS Code to use this environment

In VS Code:

Press ⌘ + Shift + P
Type:
Python: Select Interpreter
Select the interpreter that looks like:
./customer-intelligence-env/bin/python

From now on, VS Code will run your code using this environment.
